GRAVEYARD ORBIT QUOTAS 0.1.0
============================

WHAT THIS IS
  A BepInEx plugin that adds a REROLL $50 option to incomplete work orders on
  the QUOTAS board. Rerolling replaces that one card with a new random order of
  the same kind. Weapon-family orders never reroll into the same family.

REQUIREMENTS
  - Windows 10/11, or Linux / Steam Deck (Proton)
  - Graveyard Orbit installed through Steam (AppID 4654120)

INSTALL (SAME ON WINDOWS AND LINUX)
  1. Close Graveyard Orbit.
  2. In Steam, right-click Graveyard Orbit > Manage > Browse local files.
     That opens the game folder (the one containing GraveyardOrbit.exe).
  3. Download the release zip:
       https://github.com/Grokent/graveyard_orbit_reroll_quotas/releases/latest/download/GraveyardOrbit-RerollQuotas-0.1.0.zip
  4. Extract EVERYTHING from this zip into the game folder that opened in
     step 2. It only adds files; no original game file is replaced or
     modified:
       winhttp.dll
       doorstop_config.ini
       .doorstop_version
       changelog.txt
       BepInEx/...
  5. Linux / Steam Deck (Proton) ONLY: add this launch option once
     (game > Properties > Launch Options):
       WINEDLLOVERRIDES="winhttp=n,b" %command%
     Windows needs no launch options.
  6. Launch the game through Steam.

USE
  Open QUOTAS in the base.
  - Incomplete card: the lower-right key reads REROLL $50.
  - Target met: the same key becomes the normal CLAIM button.
  - Paid card: PAID, no reroll.

  A reroll:
    - charges $50 immediately (configurable; 0 = free),
    - keeps the same category (family/general/cross/purchase),
    - never returns the same weapon family for a family order,
    - resets that card's progress to 0,
    - leaves the other nine cards and the set/reward rules unchanged.

UNINSTALL
  Delete BepInEx/plugins/GraveyardOrbit.Quotas/
  Remove winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt and
  BepInEx/ only if you do not use any other BepInEx mod.

CONFIG
  BepInEx/config/agentbox.graveyardorbit.quotas.cfg

    [Reroll]
    Price = 50

NOTE
  BepInEx injects through winhttp.dll. Some antivirus tools may flag it as a
  false positive; that file is part of the standard BepInEx mod loader.
